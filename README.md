# Toxic Comment Classifier

A Machine Learning project that classifies text comments as **Toxic** or **Non-Toxic** using Natural Language Processing (NLP).

## Project Overview

This project uses text preprocessing and machine learning techniques to analyze written comments and predict whether they contain toxic language.

The project includes:
- A Jupyter Notebook for data analysis and model training.
- A Python GUI application for classifying text comments.
- A trained machine learning model.

## Technologies Used

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Jupyter Notebook
- Tkinter

## How to Run

1. Install the required Python libraries.
2. Make sure `toxicity_model.pkl` is in the same folder as `toxic_app.py`.
3. Run the application:

```bash
python toxic_app.py
```

## Note

The model and application should be tested in the target environment before use. Predictions are estimates and may not identify every toxic comment correctly.
